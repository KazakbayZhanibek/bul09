BUL BUL CORP — тёмный сайт с исправленной 3D-моделью

Загрузите содержимое архива в корень папки сайта, сохраняя структуру assets/.
Откройте index.html через веб-сервер (не file://): 3D загружается по HTTP.
Если GitHub Pages уже настроен, сохраните существующий CNAME и настройки домена.
Не нужно менять домен или DNS для этой замены файлов.

Сохранены прежний тёмный дизайн, три рисунка и три цвета.
Заменена 3D-основа футболки; служебная панель диагностики удалена.
Принты остаются прежними реконструкциями для визуализации.
Модель — эскиз, не скан и не выкройка готового изделия.
Для интерактивной 3D нужен WebGL. Реальное GPU-отображение и жесты на вашем
устройстве необходимо проверить после загрузки; в облачной среде WebGL недоступен.

Лицензия 3D-основы находится в assets/models/ATTRIBUTION.txt.
Сохраняйте атрибуцию и файлы лицензий при распространении сайта.
